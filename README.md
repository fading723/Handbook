## 📖 项目简介

`SCUT_Graduate-Handbook` 是一份面向 **华南理工大学研究生新生** 的实用手册，主要整理研一入学后高频会遇到的问题，包括：

* 🧭 校内导航与常用设施位置
* 🍱 外卖防丢、放置点建议与监控调取流程
* 🏥 生活健康、医疗、运动与日常服务
* 📚 课程资料、课件、作业、试卷与复习材料

这份手册希望帮助新同学更快熟悉校园环境，减少信息差，把更多时间留给学习、科研和生活本身。

## 🍱 外卖注意事项

外卖是研究生日常生活的重要组成部分，但也容易遇到：

* 外卖被拿错
* 外卖被偷
* 骑手放错位置
* 高峰期找不到餐
* 需要调取监控但不知道流程

本仓库整理了外卖相关经验与校内监控调取流程。

推荐查看：

👉 [外卖以及查监控](./外卖以及查监控/)
👉 [校内监控调取流程笔记](./外卖以及查监控/校内监控调取流程笔记.md)

> [!TIP]
> 外卖建议优先放在相对规范、容易定位、有人流或管理人员经过的位置。取餐时注意核对姓名、电话尾号和订单信息，避免误拿。

研究生生活不只是上课和科研，也要照顾好自己。

本手册中会逐步整理：

* 体育场、健身房、球场等运动设施
* 校内小程序与预约服务

推荐从这里开始：

👉 [研究生校园生活手册](./地图与校内设施/研究生校园生活手册.md)

> [!IMPORTANT]
> 身体不适时不要硬扛。遇到紧急情况，请优先联系急救、校方值班人员、辅导员或身边同学。
